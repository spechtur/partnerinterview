# Partnerinterview

Zu zweit, mit wechselnden Rollen: Die befragte Person wählt auf dem Handy die Fragen aus, die sie gestellt bekommen möchte, und startet ihren eigenen Timer.

- **Vorbereitung:** https://spechtur.github.io/partnerinterview/
- **Teilnahme:** `join.html?set=<slug>` (Link und QR-Code erzeugt die Vorbereitung)
- **Fragensätze:** JSON-Dateien in `saetze/` – neue Datei ablegen, dann erscheint sie in der Auswahlliste.

PHGR · PH-Bold-Design · ohne Server, ohne Login, ohne gespeicherte Daten.
